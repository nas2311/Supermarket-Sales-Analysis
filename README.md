# Supermarket sales analysis

 Objectives :

Clean and prepare the raw supermarket sales dataset.

Apply logical functions to analyze and categorize data.

Use lookup functions to retrieve and combine relevant information.

Create important Key Performance Indicators (KPIs).

Summarize data using Pivot Tables.

Develop an interactive and informative dashboard.

Identify useful sales and business insights from the dataset.

Programming Tools :-

Data Cleaning

KPI Analysis

Pivot Tables

Data Visualization

Dashboard Creation

Project Structure

The workbook contains separate sheets for the original sales data, cleaned dataset, logical functions, lookup functions, KPI analysis, Pivot Tables, and the final dashboard.

Outcome

This project helped develop practical skills in Excel-based data analysis and demonstrated how raw supermarket sales data can be transformed into meaningful reports, visualizations, and business insights for better decision-making.
